# 🎵 Mood-Based Music & Quote Recommender  
*A Java Desktop Application using OOP, GUI, and Networking*

---

## 🧠 Overview
**Mood-Based Music & Quote Recommender** is a personalized Java desktop app that recommends **motivational quotes** and **music suggestions** based on the user’s mood.  
It blends **Object-Oriented Programming (OOP)** principles with **JavaFX** for a modern UI and **networking** features to fetch online data or play local content.

This project stands out because it’s **creative, emotional, and tech-driven** — combining design, logic, and psychology into one interactive desktop experience.

## 🧩 Key Features
| Feature | Description |
|----------|--------------|
| 🎭 **Mood Detection** | Choose from moods like *Happy, Sad, Excited, Stressed, Calm, Anxious*, etc. |
| 💬 **Motivational Quotes** | Fetch from local JSON or online API (e.g., Quotable.io). |
| 🎶 **Music Suggestions** | Recommend mood-based songs (local mp3s or YouTube/Spotify links). |
| 💾 **Offline Mode** | Works completely offline with pre-saved data files. |
| 🌐 **Online Mode** | Fetch new quotes/music suggestions dynamically. |
| ❤️ **Favorites System** | Mark favorite quotes/songs and save locally. |
| 🎨 **Modern UI** | Built with JavaFX + Material Design styling (JFoenix optional). |
| ⚙️ **Settings** | Manage data folder, toggle themes, enable/disable online mode. |
